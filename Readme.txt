📌 Project Overview

An interactive Bank Marketing Campaign Performance Dashboard created using Power BI to analyze customer contacts, subscription outcomes, and campaign performance.

🎯 Objectives
Track overall campaign performance using KPIs.
Analyze subscription rates across different customer segments.
Identify trends by month and contact type.
Compare subscription performance by job and education.
Analyze subscription rates across different balance ranges.
📈 Dashboard Features
Total Contacts
Average Call Duration
Subscription Rate
Total Subscriptions
Subscription Outcome analysis
Subscription Rate by Job
Subscription Rate by Month
Subscription Rate by Contact Type
Subscription Rate by Education
Subscription Rate by Balance Range
Interactive filters for Month, Job, Education, and Contact Type
🛠️ Tools & Technologies
Power BI
DAX
Power Query
Data Visualization
Data Cleaning & Transformation
🎨 Dashboard Design

The dashboard uses a clean, professional colour palette with soft lavender, cream, dark navy, and green accents for subscription outcomes.
